# Contributing

This repository is the `let-interop` harness. Requirements and RFCs stay in [community](https://github.com/linux-engineering-tools/community).

- One topic per PR
- Every commit: `Signed-off-by: Full Name <email@domain>` ([DCO 1.1](https://developercertificate.org/))
- Fill the PR template, including the clean-room affirmation
- Fixtures must be published formats. No vendor CAD binaries
- `cargo test` must pass

[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). Stay on the engineering work.
